# 터미널 지뢰찾기

터미널에서 방향키로 하는 지뢰찾기입니다. Go와 [tcell](https://github.com/gdamore/tcell)로 만들었습니다.

📐 **설계 문서:** [docs/DESIGN.md](docs/DESIGN.md)

## 실행

```bash
go run .
```

Go 1.26 이상이 필요합니다. 실행하면 난이도를 먼저 묻습니다.

| 입력 | 난이도 | 크기 | 지뢰 |
|---|---|---|---|
| 1 | 초급 | 9 × 9 | 10 |
| 2 | 중급 | 16 × 16 | 40 |
| 3 | 고급 | 16 × 30 | 99 |

## 조작

| 키 | 동작 |
|---|---|
| 방향키 | 이동 |
| 스페이스 | 칸 열기 |
| `f` | 깃발 꽂기 / 빼기 |
| `r` | 게임오버·클리어 후 다시 시작 |
| `q`, `Esc` | 종료 |

## 특징

- **첫 클릭은 절대 안 터집니다.** 첫 칸을 연 다음에, 그 칸과 주변 8칸을 피해서 지뢰를 깝니다.
- **빈칸을 열면 주변이 한 번에 펼쳐집니다.** 재귀 대신 큐(BFS)로 펼쳐서 판이 커도 스택이 넘치지 않습니다.
- **규칙과 화면을 분리했습니다.** `board.go`는 터미널을 모르기 때문에 다른 화면(GUI 등)으로 옮겨도 그대로 쓸 수 있습니다.

## 파일 구성

```
main.go    시작
game.go    키 입력, 화면 그리기, 승패, 난이도 입력
board.go   지뢰 배치, 숫자 계산, 빈칸 펼치기
cell.go    칸 하나의 상태
utils.go   작은 도우미 함수
```
